Fill in your keys step by step. This page builds a correct .env for you. It runs entirely in your browser — nothing is sent anywhere. · View dashboard →
DEVNET ONLY — no real value. The Solana keys control devnet SOL, which is free and worthless. But your ANTHROPIC_API_KEY is a real secret — this page never transmits it (no network calls at all), yet only type it on a screen you trust. Never commit your .env (the repo's .gitignore already blocks it). A mainnet RPC URL is refused by this page and by the code.
1

Get your keys

You don't fetch the Solana keys from anywhere — you create three keypairs (all devnet, worthless). Only the Anthropic key comes from outside.

Easiest: click the green “Generate” button in steps 2–4 below — it makes a devnet keypair right here in your browser (no install, nothing sent anywhere). Alternative: run this in the project folder and paste the outputs:

npm run keygen

You need: an agent (pubkey + secret), a market (pubkey + secret), a compute-provider (pubkey only), and an Anthropic API key from console.anthropic.com (step 5).

2

The agent wallet

The wallet the agent lives or dies by. Its secret is loaded only inside the signer — never logged, never sent to the LLM.

3

Legacy market account, optional

The current paper trading loop does not use this account.

4

Compute-provider & operator

The compute-provider is an allowed destination for optional devnet transfers. The API cost is deducted from the paper book, not paid to this account.

5

LLM & network

Not needed for npm run tick:dry (mock LLM, no API cost) — but required for a real npm run tick.

6

Paper trading costs

These are simulated execution costs. They reduce the paper book when it trades. No setting guarantees profit.

✓

Your .env

Save this as a file named .env in the project root (same folder as package.json). Then run npm run tick:dry or npm run tick.
