Apex Automaton — setup

Fill in your keys step by step. This page builds a correct .env for you. It runs entirely in your browser — nothing is sent anywhere. · View dashboard →
DEVNET ONLY — no real value. These keys control devnet SOL, which is free and worthless. Still: never commit your .env (the repo's .gitignore already blocks it), and never paste secrets into a chat. A mainnet RPC URL is refused by this page and by the code.
1

Generate your keypairs

In the project folder, run this three times — once per account — and paste the outputs below. (Or use the web faucet / Solana CLI for keys you already have.)

npm run keygen

Each run prints a Public key and a Secret (b58). You need: an agent (pubkey + secret), a market (pubkey + secret), and a compute-provider (pubkey only — it just receives the burn).

2

The agent wallet

The wallet the agent lives or dies by. Its secret is loaded only inside the signer — never logged, never sent to the LLM.

3

The market (pays the agent)

A separate account that pays the agent for completed tasks — the only source of revenue. Fund it later with npm run seed:market.

4

Compute-provider & operator

The compute-provider receives the compute burn each cycle — only its public key is needed. The operator key is optional.

5

LLM & network

Not needed for npm run tick:dry (mock LLM, no API cost) — but required for a real npm run tick.

6

Economy (defaults are fine)

These control the survival pressure. The defaults keep the economy net-positive; the check below must stay green.

✓

Your .env

Save this as a file named .env in the project root (same folder as package.json). Then run npm run tick:dry or npm run tick.
